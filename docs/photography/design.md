## Scientific contract

The numerical grid is in original sensor coordinates (BGGR, origin 0,0); only photographs rotate 90° clockwise. Target raw (2301,2201), inside the prepared raw crop (2109,2009,384,384). Normalized values subtract per-site rational black levels and divide by white minus black. Readouts are sensor components before white balance/lens-shading; photo rendering applies calibrated gains to contributors, using the same bilinear kernel. Rendering never mutates measurements.
